# MANUAL DE USUARIO - SISTEMA DE GESTIÓN OTNI TEXTIL

**Proyecto:** Sistema de Gestión de Datos - Indumentaria de Trabajo y Seguridad  
**Institución:** Instituto Superior Politécnico Córdoba (ISPC)  

---

## 1. Introducción
Este manual proporciona una guía práctica e intuitiva para el uso operativo del sistema de gestión de la microempresa OTNI Textil, diseñado para optimizar el control de inventario, registro de clientes y ventas diarias.

---

## 2. Acceso al Sistema (Inicio de Sesión)
1. Inicie la aplicación ejecutable del sistema.
2. En la pantalla de bienvenida, ingrese sus credenciales de acceso:
   * **Usuario**
   * **Contraseña**
3. Presione el botón **[INGRESAR]**.
4. El sistema validará su perfil e ingresará automáticamente al Panel Principal correspondiente a su rol (**Administrador** o **Vendedor**).

---

## 3. Módulos y Funcionalidades Principales

### 📦 Módulo de Stock y Productos
* **Visualización:** Permite consultar el catálogo completo de indumentaria laboral y artículos de seguridad.
* **Búsqueda rápida:** Ingrese el código o nombre del producto para filtrar el listado en tiempo real.
* **Alta de productos:** Presione el botón `[+ Nuevo producto]`, complete la ficha (nombre, categoría, talle, precio y stock inicial) y seleccione **Guardar**.

### 👥 Módulo de Clientes
* **Gestión de Compradores:** Permite mantener actualizada la base de datos de clientes.
* **Registro:** Haga clic en `[+ Nuevo cliente]`, ingrese los datos de contacto y confirme.
* **Edición/Baja:** Seleccione un cliente de la lista para modificar sus datos o eliminarlo del registro.

### 🛒 Módulo de Ventas
* **Cargar operación:** Seleccione el cliente asignado a la venta.
* **Agregar artículos:** Busque los productos requeridos e indique la cantidad vendida.
* **Cálculo automático:** El sistema calculará automáticamente los subtotales y el monto total a cobrar.
* **Confirmación:** Al finalizar la venta, presione **Registrar Venta**. El stock de los productos vendidos se descontará de forma automática en la base de datos.

### 📊 Módulo de Reportes y Estadísticas
* Permite al usuario visualizar indicadores clave del mes:
  * Total facturado por ventas.
  * Cantidad total de prendas y accesorios vendidos.
  * Registro de nuevos clientes incorporados.

### 🔐 Módulo de Usuarios / Empleados (Solo perfil Administrador)
* Permite gestionar las cuentas de acceso del personal, asignar roles y restablecer contraseñas de seguridad.
